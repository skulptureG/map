Interaction Logic Designer Help

This is a visual planning and documentation tool for interactive installations. It describes logic, user journeys, software, signals, states, timing and fallback behaviour. It does not run or control the finished show.

1. Building a flow

Add nodes from the library and connect output dots to input dots. Click an output dot and a grey ghost cable follows the pointer. Click a compatible input dot to complete the connection. Press Esc to cancel.

The Actions & Media library includes dedicated Play Video, Stop Video and Pause Video nodes, plus Play Sound, Stop Sound and Pause Sound. The generic Media node is now labelled Other Media for non-video/non-audio actions.

2. Empty Node

＋ Empty Node sits separately at the top of the library. Use it to create a completely custom node, then add a title, description and as many inputs or outputs as required.

3. Searching and Quick Add

  • Use the Node Library search to filter all available node types.
  • Double-click empty canvas space to open Quick Add. Quick Add is positioned in screen/viewport coordinates rather than canvas coordinates, and closes automatically if the canvas zoom changes so the popup cannot drift away from the pointer.
  • Use the red × or Esc to close Quick Add without adding anything.

4. Editing nodes

Select a node to edit the title, description, input names, output names and colour in Node Inspector. Text fields update live without losing keyboard focus.

5. Node colours

Nodes use the original dark two-tone style by default. Right-click a node or use Node Inspector to choose a custom colour. The header and body retain contrasting shades. Use Reset to default to return to the standard dark style.

6. Locking nodes

Use Lock Node to prevent accidental movement, deletion, colour changes, or editing of titles, descriptions, inputs and outputs. Locked nodes remain connected and visible. Unlock the node to edit it again.

7. Copy and paste

  • Select a node and press Ctrl/Cmd+C.
  • Press Ctrl/Cmd+V to paste a copy with a small offset.
  • Node settings, ports, colour and lock state are copied. Cables are not duplicated.

8. Multi-select and group movement

Left-click and drag across empty canvas space to draw a red selection box. Nodes and white cable control points fully enclosed by the rectangle become selected. Drag the header of any selected unlocked node to move the selected group together; selected white cable points move by the same amount so carefully shaped cables stay with the group. Locked nodes are excluded. Press Esc to clear the selection.

9. Cable handling

  • Left-clicking a cable selects it only. Left-click does not delete cables.
  • Right-click a cable to change its colour or use the deliberate Delete Cable command.
  • Parallel Smart Angular cables use separate routing lanes to improve legibility.
  • Connections leave outputs and approach inputs with a short straight section before turning.

10. Cable control points

  • Hold Ctrl and left-click directly on a cable to add a control point.
  • The control point appears as a small white dot.
  • Left-drag the white dot to move that part of the cable independently.
  • Hold Ctrl and right-click the white dot to delete that control point.
  • Control points are stored with the project and cable.

11. Reconnecting an existing cable

Hover over a connected input or output dot. Click the connected dot to release that end while keeping the opposite end connected. The grey ghost cable returns and follows the pointer. Click another compatible dot to reconnect the existing cable. Press Esc to cancel and preserve the original connection.

12. Cable routing

Open Settings ⚙ to choose Curved, Angular or Smart Angular routing. Smart Angular attempts to route around node rectangles and separates coincident cable paths into lanes. Node clearance and cable separation are adjustable.

13. Grid and Snap

The Snap toggle stays in the toolbar. Grid spacing is configured in Settings. With Snap enabled, dragged nodes align to the selected interval; disable Snap for free positioning.

14. Expanding canvas

The logical canvas expands as nodes are moved or added farther to the right or downward. Nodes keep their logical positions rather than being compressed against the viewport.

15. Panning

Hold Spacebar, then left-click and drag to pan around the canvas. Panning moves the viewport camera, so nodes and cables remain aligned.

16. Zoom

  • Use the mouse wheel over the canvas to zoom around the pointer.
  • Use − and + for step zooming.
  • 100% returns to actual size.
  • Fit fits all nodes into the current viewport.
  • Zoom range is approximately 25% to 250%.

17. Minimap

The minimap in the bottom-right gives an overview of the full patch. The red rectangle represents the current viewport. It moves and resizes with panning and zooming. Click or drag inside the minimap to navigate the main canvas.

18. Undo and Redo

  • Ctrl/Cmd+Z Undo.
  • Ctrl/Cmd+Shift+Z or Ctrl+Y Redo.
  • The toolbar ↶ and ↷ buttons provide the same actions.

19. Top toolbar

Project name and New remain on the left. File and Share actions are grouped into compact menus. Zoom controls are centred. Undo, Redo, Settings and Help are fixed on the right.

20. File menu

.imap is the native Interaction Map project format. It remains human-readable JSON internally, with a format identifier and version number for future compatibility.

  • Save Project stores the editable project as an .imap Interaction Map file. The file uses JSON internally but has its own project extension.
  • Open Project opens native .imap files and also accepts older .json project files for backwards compatibility.
  • PDF Export creates a clean print view.

21. Sharing

  • Share View Only creates a locked presentation-style link. Viewers can add, edit, move and delete yellow feedback notes, but cannot alter nodes, cables or routing.
  • Use Copy Feedback Link to send the annotated read-only patch back to the designer.
  • Share Editable keeps the editing interface available.
  • Project name and graph data travel with the share link.

22. PDF Export

Choose A4 or A3 and portrait or landscape. Export calculates the bounds of the complete patch, including long routed cables, then proportionally fits the patch into the printable area with a small safety margin. The editor UI, minimap, menus and inspector are excluded.

23. Suggested installation structure

A useful starting flow is: Start Up → Attract State → Person Detected → Interaction → Media/Action → Complete or Timeout → Reset. Add explicit fallback routes for unavailable media, network loss, sensor failure, no interaction and shutdown behaviour.

Keyboard summary

  • Space + drag Pan
  • Mouse wheel Zoom
  • Ctrl/Cmd+C Copy node
  • Ctrl/Cmd+V Paste node
  • Ctrl/Cmd+Z Undo
  • Ctrl/Cmd+Shift+Z / Ctrl+Y Redo
  • Ctrl + click cable Add cable control point
  • Ctrl + right-click point Delete cable control point
  • Esc Cancel cable/reconnect, clear selection, or close transient UI
