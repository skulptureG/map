Interaction Logic Designer Help

This is a visual planning and documentation tool for interactive installations. It describes logic, user journeys, software, signals, states, timing and fallback behaviour. It does not run or control the finished show.

1. Building a flow

Add nodes from the library and connect output dots to input dots. Click an output dot and a grey ghost cable follows the pointer. Normal patch interaction suppresses browser text highlighting, while text remains selectable and editable inside genuine input/textarea fields. Click a compatible input dot to complete the connection. Press Esc to cancel.

The Actions & Media library includes dedicated Play Video, Stop Video and Pause Video nodes, plus Play Sound, Stop Sound and Pause Sound. The generic Media node is now labelled Other Media for non-video/non-audio actions.

The Protocols library now also includes Trigger OSC, Send MIDI Note, Send MIDI CC and MIDI Note Off for explicit message-level actions. The node library now contains 196 active node types across ten focused categories: System & Lifecycle, Triggers & Inputs, Time & Scheduling, Logic & Decisions, State & Data, Media & Content, Devices & Physical Outputs, Software, Protocols and Documentation. Search and Quick Add cover the full library.

2. Empty Node

＋ Empty Node sits separately at the top of the library. Use it to create a completely custom node, then add a title, description and as many inputs or outputs as required.

3. Searching and Quick Add

  • Use the Node Library search to filter all available node types.
  • Double-click empty canvas space to open Quick Add. Quick Add is positioned in screen/viewport coordinates rather than canvas coordinates, and closes automatically if the canvas zoom changes so the popup cannot drift away from the pointer.
  • Use the red × or Esc to close Quick Add without adding anything.

4. Editing nodes

Select a node to edit the title, description, input names, output names and colour in Node Inspector. Text fields update live without losing keyboard focus.

5. Node colours

Nodes use the original dark two-tone style by default. Right-click a node or use Node Inspector to choose a custom colour. The header and body retain contrasting shades. Use Reset to default to return to the standard dark style.

6. Locking nodes

Use Lock Node to prevent accidental movement, deletion, colour changes, or editing of titles, descriptions, inputs and outputs. Locked nodes remain connected and visible. Unlock the node to edit it again.

7. Copy and paste

  • Select a node and press Ctrl/Cmd+C.
  • Press Ctrl/Cmd+V to paste a copy with a small offset.
  • Node settings, ports, colour and lock state are copied. Cables are not duplicated.

8. Multi-select and group movement

Left-click and drag across empty canvas space to draw a red selection box. Nodes and white cable control points fully enclosed by the rectangle become selected. Drag the header of any selected unlocked node to move the selected group together; selected white cable points move by the same amount so carefully shaped cables stay with the group. Locked nodes are excluded. Press Esc to clear the selection.

9. Node IDs and Flow Checker

Every node has an automatic reference such as N01, N02 and N03. Use Check Flow to report unreachable nodes, missing incoming or outgoing connections, unhandled Finished/Timeout/Error outputs, dead ends and missing reset routes. Click a report item to locate the node.

10. Cable labels

Right-click a cable and type a label. Labels appear as compact cable-coloured bubbles at the cable midpoint. Clear the label field, use Delete Label in the cable menu, or hover over the label bubble and use its × button. Label deletion does not affect the cable itself.

11. Groups

Create Groups from the standalone Group button. Groups are resizable coloured frames behind nodes; edit title/colour in the Inspector, drag the header to move the Group and enclosed nodes/control points together, and lock when needed. Clicking or dragging the Group itself never starts the red marquee-selection rectangle behind it; marquee selection only begins on genuinely empty canvas space.

10. Trace Journey

Select a starting node and press Trace. All reachable downstream nodes/cables highlight while unrelated content dims. Cyclic flows are handled safely. While Trace is active, the Trace buttons show a green status dot and highlighted state. Press Clear to remove both the journey highlight and the Trace indicator.

11. Cable Legend

An editable Cable Legend appears above the Canvas Map. Labels are blank by default and can be typed into directly without interrupting keyboard focus. Settings can independently show/hide the Cable Legend and Canvas Map. Use the small button in the Cable Legend header to minimise the key to a compact title bar; press it again to expand the full key. The collapsed state is saved in the .imap project and also works in Presentation Mode.

12. Cable handling

  • Left-clicking a cable selects it only. Left-click does not delete cables.
  • Right-click a cable to change its colour, set Flow Direction, or use the deliberate Delete Cable command. Flow options are Forward →, Backward ← and Bi-directional ↔. Forward is the default for every new and legacy cable. Settings offers Animated flow or Fixed with arrows, plus a separate Show cable arrows toggle. Animated flow uses moving dashes; Fixed uses solid cables with repeated SVG arrowheads centred directly on top of the cable path. Cables have a wider invisible click target, so dashed lines remain easy to select. PDF printing always uses the fixed-arrow version with arrows shown, even when cable arrows are hidden in the editor.
  • Parallel Smart Angular cables use separate routing lanes to improve legibility.
  • Connections leave outputs and approach inputs with a short straight section before turning.

10. Cable control points

  • Hold Ctrl and left-click directly on a cable to add a control point.
  • The control point appears as a small white dot.
  • Left-drag the white dot to move that part of the cable independently.
  • Hold Ctrl and right-click the white dot to delete that control point.
  • Control points are stored with the project and cable.

11. Multiple connections

Every input and output port supports multiple simultaneous cables. Click an output repeatedly to create additional branches, and multiple outputs may connect into a single input.

12. Reconnecting an existing cable

Hover over an input or output dot. Small numeric badges appear when more than one cable uses the same port. Ports can carry multiple cables. A normal click on an output starts another connection even when that port is already in use. Multiple cables can also terminate on the same input. To deliberately reconnect a single existing cable end, hold Alt and click a port that has exactly one cable attached; the opposite end stays connected. The grey ghost cable returns and follows the pointer. Click another compatible dot to reconnect the existing cable. Press Esc to cancel and preserve the original connection.

12. Cable routing

Open Settings ⚙ to choose Curved, Angular or Smart Angular routing. Smart Angular attempts to route around node rectangles and separates coincident cable paths into lanes. Node clearance and cable separation are adjustable.

13. Grid and Snap

The Snap toggle stays in the toolbar. Grid spacing is configured in Settings. With Snap enabled, dragged nodes align to the selected interval; disable Snap for free positioning.

14. Expanding canvas

The logical canvas expands in every direction. Nodes can be moved left of the original zero point as well as right, up and down, with additional canvas generated around the patch. Nodes keep their logical positions rather than being compressed against the viewport.

15. Panning

Hold Spacebar, then left-click and drag to pan around the canvas. Panning moves the viewport camera, so nodes and cables remain aligned.

16. Zoom

  • Use the mouse wheel over the canvas to zoom around the pointer.
  • Use − and + for step zooming.
  • 100% returns to actual size.
  • Fit fits all nodes into the current viewport.
  • Zoom range is approximately 25% to 250%.

17. Minimap

The minimap in the bottom-right gives an overview of the full patch. The red rectangle represents the current viewport. It moves and resizes with panning and zooming. Click or drag inside the minimap to navigate the main canvas.

18. Undo and Redo

  • Ctrl/Cmd+Z Undo.
  • Ctrl/Cmd+Shift+Z or Ctrl+Y Redo.
  • The toolbar ↶ and ↷ buttons provide the same actions.

19. Top toolbar

Project name and New remain on the left. File and Share actions are grouped into compact menus. Zoom controls are centred. Undo, Redo, Settings and Help are fixed on the right.

20. Settings

Settings is organised into tabs for Canvas, Nodes, Cables, Interface, Analysis, Presentation, Export and Saving. Project-specific visual settings are stored in .imap; browser autosave uses local storage. Restore Defaults returns the configurable options to the recommended defaults.

20. Scenes

Scenes record a named presentation journey without changing the patch. Open Scenes, create and rename a Scene, press Record, then click nodes and cables in order. When Auto-insert connecting cables is enabled, clicking two connected nodes records the unique cable between them automatically. Add timed Pause steps, choose a Scene colour, duplicate or delete Scenes, and remove individual steps. Play a Scene in the editor or Presentation Mode. Bypass Scenes immediately stops recording/playback, closes the Scenes panel and returns to normal patch editing. Export is shown on each Scene card so the required Scene can be exported directly. The WebM/MP4 selector at the top of the Scenes panel controls the format for that Scene export. Choose WebM or MP4, then the browser records the current tab/screen, automatically plays that specific Scene in Presentation Mode, and downloads the result. Scene recording uses WebM with VP8 where supported for dependable browser recording and Windows compatibility. MP4 recording is intentionally disabled because some browsers can report MP4 support while producing files Windows cannot decode correctly. For the cleanest result, choose the current browser tab when the browser recording picker appears. Scene references are stored in .imap; missing deleted nodes or cables are flagged rather than causing an error. Each Scene element has its own editable duration. New nodes default to 3.0 seconds and cables default to 1.0 second. Pause still asks for a duration when inserted. Scene timing and playback behaviour are configured in Settings → Presentation. Video export records the actual Interaction Logic Designer presentation at approximately 30 fps and 10 Mbps. Before recording it enters Presentation Mode and applies FIT so the whole patch is visible. Choose This Tab/Current Tab in the browser picker. Recording remains completely client-side and performs no server upload. WebM is the broadly available option; MP4 availability depends on the current browser encoder support and is checked before recording.

20. Presentation Mode

File → Presentation Mode opens a full-screen kiosk view. Editing panels, handles, delete controls and connection-count badges are hidden. Basic floating controls provide Zoom, 100%, Fit, Trace, Clear and Exit. Click a node to select the starting point for Trace. Space + drag pans, the mouse wheel zooms, and Esc exits.

21. File menu

.imap is the native Interaction Map project format. It remains human-readable JSON internally, with a format identifier and version number for future compatibility.

  • Save Project stores the editable project as an .imap Interaction Map file. The file uses JSON internally but has its own project extension. Save Project stores the complete workspace, including nodes, cables, groups, Scenes and their per-step timings, legend entries, feedback notes, all Settings values, and the current zoom/pan view.
  • Open Project opens native .imap files and also accepts older .json project files for backwards compatibility.
  • PDF Export creates a clean print view.

21. Sharing

  • Share View Only creates a locked presentation-style link. Viewers can add, edit, move and delete yellow feedback notes, but cannot alter nodes, cables or routing.
  • Use Copy Feedback Link to send the annotated read-only patch back to the designer.
  • Share Editable keeps the editing interface available.
  • Project name and graph data travel with the share link.

22. PDF Export

Choose A4 or A3 and portrait or landscape. Export calculates the bounds of the complete patch, including long routed cables, then proportionally fits the patch into the printable area with a small safety margin. The editor UI, minimap, menus and inspector are excluded.

23. Suggested installation structure

A useful starting flow is: Start Up → Attract State → Person Detected → Interaction → Media/Action → Complete or Timeout → Reset. Add explicit fallback routes for unavailable media, network loss, sensor failure, no interaction and shutdown behaviour.
