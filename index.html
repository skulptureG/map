Interaction Logic Designer Help

This page is a visual planning and documentation tool for interactive installations. It describes logic, user journeys, software, signals and fallback behaviour. It does not operate the finished show.

Build a flow

Add nodes from the library, then connect an output dot to an input dot. The grey ghost cable follows the pointer until the connection is completed. Press Esc to cancel.

Nodes

  • Use the standalone Empty Node for a completely custom node.
  • Select a node to edit its title, description, inputs, outputs and colour.
  • Lock a node to prevent movement, deletion and editing.
  • Ctrl/Cmd+C and Ctrl/Cmd+V copy and paste the selected node.

Canvas navigation

  • Hold Spacebar and left-drag to pan.
  • Use the mouse wheel to zoom around the pointer.
  • Use −, +, 100% and Fit in the centred zoom controls.
  • The minimap shows the full project; its red frame marks the current view.

Grid and routing

Keep Snap enabled to align moved nodes to the grid. Grid spacing and cable routing options are in Settings. Smart Angular routing separates cable lanes and avoids nodes where possible.

Cables

Left-click selects a cable. Right-click opens cable colours and the deliberate Delete Cable action. A normal left-click never deletes a cable.

Undo, save and share

  • Ctrl/Cmd+Z undo; Ctrl/Cmd+Shift+Z or Ctrl+Y redo.
  • File contains Save JSON, Load JSON and PDF Export.
  • Share contains editable and view-only links.

Typical installation flow

Start Up → Attract State → Person Detected → Interaction → Media or Action → Complete or Timeout → Reset. Add fallback routes for unavailable media, network loss, sensor failure and inactivity.
